# 🌐 Cultural Arts Website

This is the official website for the **Cultural Arts project**.

It is built using **Astro** and **Tailwind CSS** to provide a fast, simple, and modern web experience.

---

## ✨ About the Project

Cultural Arts is a digital platform focused on:

- Cultural heritage and art documentation  
- Experimental AI tools for cultural analysis  
- Research and applied technology in cultural domains  
- Open and long-term knowledge development  

The project is independent and evolves through research and individual contributions.

---

## 🚀 Tech Stack

- [Astro](https://astro.build/) – Static site framework  
- [Tailwind CSS](https://tailwindcss.com/) – Styling  
- Markdown / MDX – Content system
